Lexdeck's first public release brings local flashcards to the terminal on Linux,
macOS, and Windows. Download the archive for your system below, extract it, and
run `lexdeck` (`lexdeck.exe` on Windows). No Python installation is needed.

### Highlights

- Practice every active card once per session in random or A–Z order.
- Record a remembered card with `y`; reveal a missed card with `n` and continue
  when ready.
- Add, search, edit, and archive cards in the TUI or scriptable CLI.
- Export selected cards to PDF, Excel, or UTF-8 text. Unicode PDF fonts are
  included with the application.
- Keep cards and recall history in a local SQLite database, with no account or
  cloud dependency.

See the [installation guide](https://github.com/mouransad/lexdeck#install-a-release)
for platform-specific commands, data backup instructions, and keyboard help.
Each archive has a matching entry in `SHA256SUMS.txt`; build provenance is
available through GitHub artifact attestations.

The macOS and Windows executables are currently unsigned, so those systems may
show an opening warning. Linux binaries are built on Ubuntu 22.04 and may not
run on older distributions.
