This release makes selecting and exporting cards easier from the library.

### Highlights

- Select an inclusive range of visible cards with `Shift+L` or `Shift+Enter` in
  selection mode. The range starts at the card highlighted when selection mode
  opens, or the last card you toggled.
- See clear `[x]` and `[ ]` selection markers in the library.
- Fit more cards on each PDF page with a compact Content/Meaning layout. Long
  entries continue onto the next page.

Download the archive for your system below and follow the
[installation guide](https://github.com/mouransad/lexdeck#install-a-release).
Each archive includes third-party license notices and texts. `SHA256SUMS.txt`
and GitHub build attestations are available for verification.

The macOS and Windows executables are unsigned, so those systems may show an
opening warning. Linux binaries are built on Ubuntu 22.04 and may not run on
older distributions.
