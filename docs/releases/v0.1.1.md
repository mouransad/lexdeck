This maintenance release adds complete third-party license notices and license
texts to every standalone download. Lexdeck's study, library, and export behavior
is unchanged from v0.1.0.

Download the archive for your system below and follow the
[installation guide](https://github.com/mouransad/lexdeck#install-a-release).
Each archive includes `THIRD_PARTY_NOTICES.txt`, the license texts for bundled
libraries and Python, Lexdeck's MIT license, and the DejaVu font license.
`SHA256SUMS.txt` and GitHub build attestations are also available for verification.

The macOS and Windows executables are unsigned, so those systems may show an
opening warning. Linux binaries are built on Ubuntu 22.04 and may not run on
older distributions.
